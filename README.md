# Student Data Manager

A simple Python project for managing and analyzing student grade data stored in a CSV file.

This project was created as part of my Python learning and focuses on working with functions, CSV files, lists, dictionaries, loops, user input, and basic data analysis.

## Features

The program includes a menu where the user can:

- View all students
- Search for a student and display their subjects and marks
- View all students and marks for a selected subject
- Find the highest mark in a selected subject
- Calculate the average grade for a selected subject
- Add a new student record
- Find the highest mark overall
- Exit the program

## Technologies

- Python
- CSV file handling
- `csv.DictReader`
- `csv.DictWriter`

## Files

- `student_data_manager.py` - Main Python program
- `practice_students.csv` - Student data used by the program

## How to Run

Make sure Python is installed, then run:

```bash
python student_data_manager.py
```

The program will display a menu where you can select an option by entering a number.
